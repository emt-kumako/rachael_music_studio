Problem

Timing module 仍從 DOM 讀取；tick 把 schedule、audio、UI 綁在一起；測試只能 fork implementation。

Solution

純輸入（音數、方向、模式、拍數、BPM）進一個 deep module，輸出 sequence／beat plan／時長。

Wins

  • locality: 4/4 收束規則一處
  • leverage: play／step／tests 共用
  • interface 即測試面
  • 刪除 fork 的 buildBeatPlan
